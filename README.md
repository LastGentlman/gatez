# Gate Z: The ZK Onboarding Protocol

**Gate Z** es la autoridad definitiva en onboarding, noticias y estrategia para el ecosistema Zero-Knowledge (ZK) y Layer 2.

## Misión
Convertir gatez.io en el "Portal" de referencia para usuarios y capital que buscan entrar en redes como ZkSync, Starknet, Scroll y Linea.

## Enfoque
- **Alto Rendimiento:** Contenido directo, accionable y técnico.
- **Automatización:** Curación y generación impulsada por n8n y Python.
- **Identidad:** Minimalista, futurista y soberana.
